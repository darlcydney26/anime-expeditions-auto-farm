# Anime Expeditions Auto Farm Macro

Runs expeditions for you on repeat, so the grind happens whether you are at the keyboard or not.

## Download

[Download the latest release](../../releases/latest) — portable build, no installer and no account.

## What it does

- Records a full run from your own keyboard and mouse
- Loops the recorded sequence until you stop it
- Second sequence for restarting expeditions and claiming rewards
- Delays in milliseconds with random jitter
- Global hotkey to start and stop without leaving the game
- Named profiles, one per raid, swapped in a click
- Run counter showing completed loops
- Small installer, no extra components, free and open source (MIT)

## Requirements

Windows 10 or 11, 64-bit. No admin rights, nothing written to the registry.
